## Synthèse de ma veille technologique

- **Définition en une phrase :** La modularité logicielle consiste à diviser le code en plusieurs parties réutilisables afin d'éviter la répétition et de faciliter la maintenance.

- **Problème résolu pour le projet :** Éviter de répéter le même code HTML et PHP dans plusieurs pages du Blog. Par exemple, au lieu de modifier le header dans 5 pages différentes, on le met dans un seul fichier réutilisable.

- **Mes 3 mots-clés :** Inclusion (require_once) — Fonctions réutilisables — Principe DRY (Don't Repeat Yourself).
